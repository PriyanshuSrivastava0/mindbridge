# MindBridge AI — Production Web Application
## AI-Powered Mental Health Risk Detection & Personalized Intervention Platform

### Quick Start
```bash
# Start development server
npm run dev

# Run automated test suite (Unit & Integration)
npm test

# Seed synthetic demo database
npm run seed

# Build production bundle
npm run build
```

The core full-stack application source code, schema, and documentation reside in [`health/`](./health).
